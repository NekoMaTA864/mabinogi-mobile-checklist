# 瑪奇 Mobile｜6 角色日週清單

GitHub Pages：<https://nekomata864.github.io/mabinogi-mobile-checklist/>

這是一個純前端、手機友善的六角色清單。未設定同步時，資料會保存在目前裝置的瀏覽器；設定 Google Sheets 同步後，今日勾選與本週進度會寫入既有試算表的「歷史紀錄」，不同裝置可以讀回同一份資料。

## Google Sheets 同步設定

1. 開啟試算表「瑪奇 Mobile｜6角色日週清單」。
2. 選擇「擴充功能 → Apps Script」，將 `Code.gs` 內容貼入並儲存。
3. 在 Apps Script 執行 `setSyncToken()`，輸入一組只給自己使用的密鑰。
4. 選擇「部署 → 新增部署 → 網頁應用程式」：執行身分選「我」，誰可以存取選「任何人」。
5. 複製部署後的 `/exec` 網址，開啟網頁版的「同步」頁，填入網址與同一組密鑰。
6. 每台裝置各設定一次；之後勾選或調整進度會同步，按「從 Google Sheets 讀取」可載入最新資料。

同步 API 只處理目前遊戲日與本週的任務列，舊的「歷史紀錄」不會清除。密鑰只存於 Apps Script Script Properties 與各裝置的瀏覽器設定，不放進公開 GitHub 原始碼。

## Google OAuth 登入版

目前前端已加入 OAuth 原型。OAuth 版直接由 GitHub Pages 呼叫 Google Sheets API，Apps Script 不參與 OAuth 流程；原本的 Token／Apps Script 同步仍保留在「同步」頁的備援區塊。

## Checklist v2 第一階段

目前網頁以不破壞舊資料為前提，配合六角色輪班玩法整理：

- 今日清單改以「兼職已處理」、「週幾地下城」、「魔族供品已處理」與「今日角色採購／交換已確認」為核心。
- 舊版「每日任務」、「銀幣清理」、「每日限購／免費商品檢查」與普通黑洞 Daily 標記仍保留相容讀取，但不再作為目前 Daily Checkbox。
- 兼職只記錄是否處理，不區分聖水、高價值或普通；星期一會顯示「週初：建議六角色優先清理兼職庫存」提示。
- 每週頁依角色顯示「不詳的召喚結界」、「黑色坑洞」、「野外首領週戰利品」、「格里斯貝恩（小格）」與其他角色週課；每週任務則維持伺服器共通、只需完成一次。
- 不詳的召喚結界改為 `0 / 7` 箭頭計數；每角色每週 7 次獎勵，達到 7 次後視為完成。既有 LocalStorage／Sheet 次數資料可直接延續。
- 黑色坑洞保留本週箭頭計數；目前沿用 14 次上限，但台服可查數字主要來自玩家交叉資料，介面標示以遊戲內顯示為準。
- 野外首領週戰利品與格里斯貝恩（小格）都是每角色每週 1 次；同一角色選哪一隻野外首領都只算一次。
- 深淵相關內容與新版白魅魔會對六角色保留，但本尊列入 Required Weekly，五個分身列為 Optional Weekly，不會阻止分身達成 Weekly 100%。
- 新增「今日主角色」輪班提示：週一至週六依序為貓又老師、貓又老師z、貓又老師zz、貓又老師o、貓又老師p、貓又老師oo；週日顯示六角色週課總盤點，提供補漏摘要。
- 新增「特殊事件」區塊：通往深淵的黑色坑洞只作看到就打的提示，不計入 Daily／Weekly 完成率，也不寫死尚未被官方確認的等級條件。
- 採購／交換頁保留原本地區、NPC、商品、Cost、Daily／Weekly、角色／帳號 Scope、證據等級與來源；追加 9/9 官方更新中有明確限制的班克爾及 NPC 商店／交換項目。

這一階段保留既有 LocalStorage key、角色任務索引與 `歷史紀錄` 欄位，因此既有 OAuth／Token 同步仍可讀取。新的帳號共用資料會以 `角色=帳號共用` 寫入同一張 `歷史紀錄`，不需要修改試算表欄位。

啟用前需要完成：

1. 在 Google Cloud 建立 OAuth consent screen。
2. 建立 Web application OAuth Client ID。
3. 啟用 Google Sheets API。
4. 將 `https://nekomata864.github.io` 加入 Authorized JavaScript origins。
5. 將需要使用的 1～2 個 Google 帳號加入測試使用者，並把同一份試算表共用給這些帳號。
6. 修改 `index.html` 頂端的 `GOOGLE_OAUTH_CLIENT_ID`。
7. 如需前端帳號白名單，填入 `ALLOWED_GOOGLE_EMAILS`；真正的資料權限仍由 Google Sheet 的共用權限控制。

OAuth Client ID 可以公開放在前端，但不要把 Client Secret、Access Token 或其他密鑰提交到 Repository。Access Token 只在目前頁面的記憶體中使用，重新整理頁面後需重新登入或授權。

OAuth 讀寫沿用既有「歷史紀錄」欄位與資料規則，並以 `重置日 + 角色 + 任務名稱 + 週期` 找到既有列；找不到時才新增資料列，不會清除歷史紀錄。

## 採購頁資料範圍

目前可追蹤的第一版項目以班克爾為主，包括珍妮佛的清淡的肉交換、艾琳的銀合金錠交換、艾頓的每週銀合金錠交換，以及吉爾摩的最高級生皮／最高級蜘蛛網週限購。採購列會以 `任務名稱=採購｜項目 ID` 寫入同一張「歷史紀錄」，不需要新增欄位或修改 `Code.gs`。

頁面也保留台服日常工具、生活資料、玩家材料保留表、巴哈 NPC 整理與使用者提供的舊 Tracker 連結，方便之後逐項核對；舊韓服資料不會自動當成台服現行資料。

採購頁目前分成以下提示：

- 「稀缺優先」：最高級生皮、最高級蜘蛛網，以及 65 等級以上角色的礦山／曠野魔力石；保留既有每角色每週限購數字追蹤。
- 「生活用途週限購」：班克爾新增的料理／加工材料；有每角色週限購，但是否買滿依實際生活路線決定。
- 「料理常備」：公開 Tracker 的配方表反覆出現的肉、鹽、高麗菜、胡椒、糖、蘋果、大蒜、檸檬、食用油、蛤蜊。這些適合列入巡店路線，但目前沒有台服官方資料支持設定成六角色固定週目標。
- 「有需求再買」：番茄、蘆筍、豌豆、草莓、冰。公開配方用途較集中，其中番茄、蘆筍、豌豆在舊 Tracker 的價格較高；沒有安排料理時不建議盲買。
- 「一般材料」：一般生皮、高麗菜、番茄只作材料提醒，不假設為每角色固定每週必買，也不計入完成度。

採購頁另加入 15 個「食材店目錄」資訊列：肉、鹽、高麗菜、胡椒、糖、番茄、蘆筍、豌豆、食用油、蘋果、大蒜、檸檬、草莓、蛤蜊、冰。這些列不會顯示勾選或箭頭，也不會寫入 LocalStorage／Google Sheets；它們用來查詢候選商品與料理用途。公開 Tracker 的舊價格、庫存數、城鎮／NPC 位置與刷新週期均標示為待核對，不當作台服規則。實際採購前仍以台服遊戲內商店為準。
